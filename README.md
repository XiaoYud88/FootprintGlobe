# 足迹地球 · FootprintGlobe

一个只给自己用的 iPhone App：打开就是一颗**自绘的 3D 地球**，用定位自动记录你去过的城市，去过的国家 → 省份 → 城市会随缩放逐级亮起来。

- 纯 SwiftUI，**零第三方地图 SDK**，不需要任何 API Key，不需要联网
- 只做中国大陆（34 个省级行政区 / 370 个地级市），边界数据打包在 App 内
- 最小单位是**地级市**（太原市、秦皇岛市……）
- 定位数据只在本机计算，不上传、不要账号

当前版本：**M0-V2（0.2.0）**

| 版本 | 内容 |
| --- | --- |
| M0-V1 `0.1.0` | 自绘地球 + 中国边界 + 定位自动记录 + 三级轮廓 |
| **M0-V2 `0.2.0`** | 修复进入中国后地图空白的投影 bug；城市记录（首次到访时间 + 故事）；点城市先填表再入册；地球拖拽惯性；界面槽位化重构 |

### M0-V2 修复的那个 BUG

**现象：** 缩放到中国，地球消失了，中国也没出现。

**根因：** 世界坐标存的是 `y = -lat`（数据 y 轴朝下），而 `ChinaMapView` 的 `CGAffineTransform` 又写了 `d: -ky`，等于把纬度翻转了两次。结果整张中国地图被推到屏幕外 —— 北京算出来的 y 是 985，而屏幕高只有 852。

**修法：** 把投影逻辑抽成 `Core/ChinaProjection.swift`，符号改正为 `d: +ky`，并让「屏幕点 ↔ 经纬度」双向可逆，这样后续做「点地图选城市」也能直接复用。同时补了一条回归断言：旧公式下北京必须在屏幕外、新公式下必须在屏幕内。

### 界面为什么会越来越多组件也不乱

`Theme.swift` 里加了设计令牌层 `Theme.Layout`（页面留白 18 / 卡片圆角 18 / 控件高 40 / 浮动间距 10 ……）和 `Theme.Typo`（title / subtitle / label / body / caption / number 六档字阶）。主界面按槽位划分：

```
header      标题 + N/370 城市 · N 省 · N 段故事（点进度环进清单）
zoomRail    右侧上下 +/− 与当前层级（地球 / 国家 / 省份 / 城市）
bottomStack 当前城市 chip → 权限提示卡（可关）→ 底部 dock
overlay     toast
```

新组件进来只占一个新槽位，间距和字阶都从令牌取，不需要重新调版式。记录面板 `CityRecordSheet` 也是由卡片拼的，加一节新的「照片 / 同行人 / 温度」只要再写一个 card。

### 关键设计

**为什么能不用地图 SDK？** 因为只需要中国一个国家的行政边界。数据是离线的（2.4 MB），投影是在 `Canvas` 里自己算的，所以既没有配额、也没有网络依赖。

**坐标系。** 边界数据来自 DataV GeoAtlas，是 **GCJ-02**；iOS 的 `CLLocation` 是 **WGS-84**。所以在定位入口用 `GeoMath.wgs84ToGcj02` 转换一次，之后全链路都用 GCJ-02，不需要在绘制时反复纠偏。

**为什么不需要定时轮询？** iOS 不允许后台定时采样。这里用的是 `startMonitoringSignificantLocationChanges()`（显著位移被动唤醒，几乎不耗电）+ 前台 `requestLocation()`。系统没唤醒时，候选会留在「待确认」里让人手动确认。

**防误记的判定（`VisitTracker`）**

```
进城            → 只生成候选（不写记录）
候选            → sampleCount >= 2 且 spanHours >= 3   ⇒ 转正
离开时还没达标  → 丢弃（这就是高铁经过进不了名单的原因）
高速 + 停留极短 → 直接判为路过
已在名单再进城  → 只更新 lastSeen / sampleCount / 天数
```

停留阈值（2/3/4/6 小时）和最少采样次数（2–5 次）都能在设置里改。

## 二、怎么跑起来

环境：macOS + **Xcode 16 或更新**（iOS 17+ 真机 / 模拟器）。

1. 打开 `FootprintGlobe.xcodeproj`
2. 选中 `FootprintGlobe` target → **Signing & Capabilities**
   - 勾选 `Automatically manage signing`
   - `Team` 选你自己的 Apple ID（免费账号即可）
   - 如果 `Bundle Identifier` 冲突，把 `com.personal.footprintglobe` 改成任意唯一值
3. 手机连上电脑，选自己的设备，⌘R 运行
4. 首次启动按提示给定位权限：**使用 App 期间** + **始终允许**（后台补点必需）

> 用免费开发者账号签的 App，**7 天后会失效**，重新 ⌘R 一次即可；证书过期后桌面图标点开会闪退，属正常现象。

## 三、边界数据

- 来源：阿里云 DataV GeoAtlas 行政区划（`_full.json`），坐标系 **GCJ-02**
- 处理：只保留外环 → Douglas–Peucker 简化（省 0.006°、市 0.004°）→ 丢弃跨度 < 0.035° 的碎岛 → 合并成单个 `boundaries.json`
- 规模：34 个省级、370 个地级市、134,352 个点、约 2.4 MB
- 加载耗时：真机 / 模拟器约 90 ms，一次性在启动时完成

数据仅供个人记录使用，版权归原数据提供方。

## 六、怎么验收这一版（M0-V2）

按顺序走一遍，5 分钟能看完：

1. **打开 App** —— 看到地球，并且自动转到你所在的位置。
2. **拖一下地球再松手** —— 球应该继续滑一小段、逐渐变慢才停（不是松手就钉住）。甩得越快，滑得越远。
3. **点底部「进入中国」** —— 这是 V1 的 BUG 点。现在应该看到整块中国、省界清楚；地球本身退出画面是正常的（它换成了平面图）。
4. **双指放大到省份 → 城市** —— 省界消失、市界出现、市名逐个冒出来；右侧轨道会显示当前层级「地球 / 国家 / 省份 / 城市」。
5. **点底部「城市清单」→ 随便点一个城市** —— 现在**不会**直接变成去过，而是弹出记录面板。选时间（有「今天 / 上周 / 上月 / 去年」快捷按钮）、写两句话，点**保存** → 这个城市才变紫、进入「去过」。
6. **再点同一个城市** —— 面板里会带出上次填的时间和故事，可以改、可以删除记录。
7. **回主界面看顶部** —— 「N/370 城市 · N 省 · N 段故事」里的「N 段故事」应该等于你写了备注的城市数。
8. **杀掉 App 重开** —— 时间和故事都还在（存在沙盒 `footprint.json` 里）。
9. **自动记录那条线** —— 手机上不好现场验，正常用法是：在这个城市待满 3 小时以上、让 App 在后台被唤醒两次，它就会自己转正。没转正的会出现在底部「待确认」里，点一下可以手动确认。

已知限制：台湾省的市级数据源里只有省级轮廓，暂按一个整块显示；长时间静止系统可能不唤醒，靠「待确认」兜底；M0 还没有 iCloud / 跨设备同步。
