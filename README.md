# 足迹地球 · FootprintGlobe

一个只给自己用的 iPhone App：打开就是一颗**自绘的 3D 地球**，用定位自动记录你去过的城市，去过的国家 → 省份 → 城市会随缩放逐级亮起来。

- 纯 SwiftUI，**零第三方地图 SDK**，不需要任何 API Key，不需要联网
- 范围：**中国大陆（34 省 / 370 市）+ 日本（47 都道府县）+ 南极洲 + 北极**，边界数据打包在 App 内
- 最小单位是**地级市**（太原市、秦皇岛市……）
- 定位数据只在本机计算，不上传；账号是**可选的**，也完全留在这台手机上

## 一、这一版做了什么（M1-V3）

### 1.1 删掉晨昏线

上一版的晨昏线在小屏上很难看：径向渐变的 stop 只够画几档，交界处糊成一片脏灰色；球面本身已经有上下渐变和大气光晕，再叠一层「明暗」就成了三层灰。

| 之前 | 现在 |
| --- | --- |
| 每 60 秒算太阳直射点，以它为圆心铺「透明 → 黑」的径向渐变，外圈再压一条橙色暖带 | **整段删掉**。改成固定方向的**左上高光**（`drawHighlight`）：从左上角往右下衰减的一层白光，只负责让球看起来是圆的、有体积感 |
| 暗部会随时间移动，但边界脏、颜色灰 | 光源固定，永远干净；球面靠「双层大气 + 上下渐变 + 边缘描边」立住 |

代码：`UI/GlobeView.swift` 里的 `drawDayNight` 换成了 `drawHighlight`，`GlobeView` 也不再需要 `sun` 参数。太阳相关计算只剩月亮还在用（`Core/SolarPosition.swift` 月相部分）。

### 1.2 修好护照海报分享

**现象：** 护照页左上角的分享按钮，点下去是一片灰，等很久什么都不出来。

**根因有三层，叠在一起就成了「点了没反应」：**

1. 按钮的 action 里**同步**调 `ImageRenderer` 渲染整张海报 —— 主线程被卡住几秒，弹窗动画根本没机会开始。
2. 渲染结果放 `@State posterImage`，然后 `showPoster = true`；但 sheet 的内容写的是 `if let posterImage` —— 一旦渲染返回 `nil`（3 倍渲染在旧机型上很容易吃内存失败），sheet 里就是**一个空的灰页**。
3. 存到相册 / 分享是用 `UIActivityViewController` 包成 SwiftUI sheet，套在「主页 → 护照 sheet → 海报 sheet」的**第三层**上，系统经常直接摊成空白。

**修法：**

| 改动 | 说明 |
| --- | --- |
| **先弹窗，再渲染** | 按钮只做 `showPoster = true`；渲染搬进 `.task` 里，弹窗先显示「正在画海报…」，动画走完再算 |
| **三段降级** | 正常渲染 → 失败就渲染**简化版**（地球位置换成渐变圆 + 地球图标，数据全对）→ 再失败才显示「这张图没渲染出来」+ 重新生成按钮。**任何情况下都有东西可看**，不会再空着 |
| **分享不再套 sheet** | 新写 `SharePresenter`：找到最顶层的 `UIViewController`，直接 `present(UIActivityViewController)`，绕开 SwiftUI 的嵌套 sheet |
| **渲染倍率 3 → 2.6** | 依旧是 `ImageRenderer`（不是截屏，放大看字是干净的），但内存压力小一截，旧机型不容易返回 `nil` |

### 1.3 自动旋转 + 陀螺仪视差

| 能力 | 实现方式 |
| --- | --- |
| **自动旋转** | 24 fps 的 `Task` 循环，每帧经度 +0.16°，差不多**90 秒一圈**。手指一碰（拖动 / 双指缩放）就重新计时，**停手 8 秒**才又开始转 |
| **什么时候不转** | 关掉开关不转；正在跟随定位不转；缩到平面地图（`zoom < 0`）不转；App 退到后台不转 |
| **陀螺仪视差** | `CMMotionManager` 读 `deviceMotion.gravity`（不用陀螺仪角速度，那个会漂），1/15 秒一次，`0.82 / 0.18` 低通滤波；让**球面中心**偏最多 3.4°（横向）/ 2.6°（纵向），而**星空不动** —— 前后景分开，才有纵深 |
| **省电** | 变化小于 0.012 才发布新值，静止时一次 UI 刷新都不做 |

开关在 `设置 → 地球`，视差那一行会显示「已开启 / 不可用」（模拟器没有陀螺仪）。

### 1.4 四套配色主题

`设置 → 外观` 现在是一个四段选择器，**手动切、立即生效、下次打开还是这个**（不跟随系统）。

| 主题 | 底色 | 品牌色 | 气质 |
| --- | --- | --- | --- |
| **深空** | 近黑蓝 | 紫 | 原来的默认，晚上看最舒服 |
| **日光** | 米白 | 靛蓝 | 白天户外，屏幕反光也看得清 |
| **纸质地图** | 牛皮纸 + 墨线 | 砖红 | 老地图的感觉：海洋是纸黄，陆地偏土色，球面撒了一层极淡的纸点 |
| **霓虹夜航** | 紫黑 | 青 | 天上的星是薄荷白、星云偏粉紫，球面大陆是深紫，标记亮青色 |

实现上没动任何页面代码：`Theme.Palette` 里补了 `globeTop / globeBottom / atmosphere` 三个字段，四套色板各自填值，页面里照旧只写 `Theme.brand`、`Theme.textSecondary` 这种语义色。星空按主题换星色和银河亮度，纸质地图那套额外画了 420 个极淡的纸点（固定种子，不会每次重开都变）。

### 1.5 本地可选账号

**不需要账号也能用全部功能**；想用的话在 `设置 → 账号` 里注册，注册完能设头像和昵称。

| 能力 | 实现方式 |
| --- | --- |
| **手机号 + 密码直接注册** | 11 位、1 开头、密码 ≥ 6 位、两次输一致；昵称不填就用「旅行者 + 手机后 4 位」。同一个号再注册 = **重设密码** |
| **完全没有数据库** | 档案写在 `Documents/account.json`，头像写在 `Documents/Avatar/avatar.jpg`（512 px，JPEG） |
| **密码不进数据库、也不存明文** | `PBKDF2-HMAC-SHA256`，**随机 16 字节盐 + 12 万轮**，盐和哈希一起写进**钥匙串**（`kSecAttrAccessibleWhenUnlockedThisDeviceOnly`：只在这台机器、解锁后才读得到，不进 iCloud 备份）。就算整个 App 目录被拷走也反推不出原密码 |
| **注册后** | 头像（相册选图）、昵称（≤ 16 字），首页左上角出现小头像，点它进设置 |
| **退出登录** | 只清登录状态，档案和头像都还在，重新输密码就能回来 |
| **恢复备份之后** | 档案会跟着回来，但钥匙串不跟着走，所以要重新注册一次（等于重设密码）—— 界面上有说明 |

> 为什么不做云端：这一版没有后台。真要做账号体系，就得有服务器、有密码找回短信、有隐私协议，对一个只给自己用的 App 来说不划算。现在这套的定位是「本机上的一份身份」：能有个头像、有个昵称挂在地球上，就够了。

### M0-V2 修复的那个 BUG（留个记录）

**现象：** 缩放到中国，地球消失了，中国也没出现。

**根因：** 世界坐标存的是 `y = -lat`（数据 y 轴朝下），而 `ChinaMapView` 的 `CGAffineTransform` 又写了 `d: -ky`，等于把纬度翻转了两次。结果整张中国地图被推到屏幕外 —— 北京算出来的 y 是 985，而屏幕高只有 852。

**修法：** 把投影逻辑抽成 `Core/ChinaProjection.swift`，符号改正为 `d: +ky`，并让「屏幕点 ↔ 经纬度」双向可逆。

### M1-V2 那个「灰屏」的教训（留个记录）

**现象：** 护照页分享按钮，点了是一片灰，等半天什么都没有。

**教训：** 三件事不能同时做 —— ① 在主线程同步跑重活（`ImageRenderer`）、② 用 `if let` 包住 sheet 的整个内容（失败就是空白页）、③ 在已经有 sheet 的层级再套 sheet 弹系统面板。现在的规矩是：**按钮只改状态**，重活进 `.task`，系统面板走 UIKit 顶层 present，并且永远留一条降级路径。

### 界面为什么会越来越多组件也不乱

`Theme.swift` 里是设计令牌层 `Theme.Layout`（页面留白 18 / 卡片圆角 18 / 控件高 40 / 浮动间距 10 / 头像 44 / 每城照片 3 张……）和 `Theme.Typo`（title / subtitle / label / body / caption / number / bigNumber）。主界面按槽位划分：

```
header      小头像（登录后才有）+ 标题 + N/419 城市 · N 省 · N 段故事（点进度环进清单）
zoomRail    右侧上下 +/− 与当前层级（地球 / 国家 / 省份 / 城市）
bottomStack 当前城市 chip → 权限提示卡（可关）→ 底部 dock
toastLayer  轻提示
celebration 点亮动画（全屏浮层）
```

新组件只占一个新槽位，间距和字阶都从令牌取。记录面板 `CityRecordSheet` 由卡片拼成（状态 / 时间 / 故事 / 照片 / 标签 / 星级 / 删除），护照页 `PassportView` 也是卡片拼的。

### 关键设计

**为什么能不用地图 SDK？** 因为只需要两个国家 + 两极的行政边界。数据是离线的（边界 2.8 MB + 世界底图 186 KB），投影是在 `Canvas` 里自己算的，所以既没有配额、也没有网络依赖。

**坐标系。** 中国边界来自 DataV GeoAtlas，是 **GCJ-02**；iOS 的 `CLLocation` 是 **WGS-84**。所以在定位入口用 `GeoMath.wgs84ToGcj02` 转换一次，之后全链路都用 GCJ-02。日本 / 南极来自 Natural Earth 系数据，本就是 WGS-84，**不参与中国那套纠偏**，只在绘制时直接用。

**北极怎么来的？** 北极没有陆地、没有行政边界，也不可能有人长期停留。为了让「极北」这件事能被记录，加载边界时**合成**了一个很小的极区圆帽（覆盖极点附近，code `AR` / 城市 `AR-POLE`，中心 15°E 88°N）：能画、能点、能手填，但不参与定位判定和面积占比。

**为什么不需要定时轮询？** iOS 不允许后台定时采样。这里用的是 `startMonitoringSignificantLocationChanges()`（显著位移被动唤醒，几乎不耗电）+ 前台 `requestLocation()`。系统没唤醒时，候选会留在「待确认」里让人手动确认。

**防误记的判定（`VisitTracker`）**

```
进城            → 只生成候选（不写记录）
候选            → sampleCount >= 2 且 spanHours >= 3   ⇒ 转正
离开时还没达标  → 丢弃（这就是高铁经过进不了名单的原因）
高速 + 停留极短 → 直接判为路过
已在名单再进城  → 只更新 lastSeen / sampleCount / 天数
```

停留阈值（2/3/4/6 小时）和最少采样次数（2–5 次）都能在设置里改。

**密码为什么不进数据库？** 因为没有数据库。就算以后有了，PBKDF2 + 随机盐 + 高轮数这套也应当保留：数据库里只该放「不可逆的验证材料」，而不是能用密码直接换算出来的东西。现在的做法是把它放在比文件更安全一点的地方（钥匙串），并且标成 `ThisDeviceOnly`，让它连 iCloud 备份都进不去。

## 四、怎么跑起来

环境：macOS + **Xcode 16 或更新**（iOS 17+ 真机 / 模拟器）。

1. 打开 `FootprintGlobe.xcodeproj`
2. 选中 `FootprintGlobe` target → **Signing & Capabilities**
   - 勾选 `Automatically manage signing`
   - `Team` 选你自己的 Apple ID（免费账号即可）
   - 如果 `Bundle Identifier` 冲突，把 `com.personal.footprintglobe` 改成任意唯一值
3. 手机连上电脑，选自己的设备，⌘R 运行
4. 首次启动按提示给定位权限：**使用 App 期间** + **始终允许**（后台补点必需）；第一次加照片时会问相册权限

> 用免费开发者账号签的 App，**7 天后会失效**，重新 ⌘R 一次即可；证书过期后桌面图标点开会闪退，属正常现象。

## 五、边界数据

| 数据 | 来源 | 坐标 | 规模 |
| --- | --- | --- | --- |
| 中国 34 省 / 370 市 | 阿里云 DataV GeoAtlas `_full.json` | GCJ-02 | 简化后 13.4 万点 |
| 日本 47 都道府县 | Natural Earth 10m admin-1（经 jsdelivr 镜像取得） | WGS-84 | 47 个多边形 |
| 南极洲 | Natural Earth 50m 国界 | WGS-84 | 1 个整块 |
| 北极地区 | 代码合成极性圆帽 | — | 24 点 |
| 世界底图 | Natural Earth 50m 国界 | WGS-84 | 242 国 / 10,450 点 |

处理流程：只保留外环 → Douglas–Peucker 简化（省 0.006°、市 0.004°）→ 丢弃跨度 < 0.035° 的碎岛 → 合并成单个 `boundaries.json`。加载耗时约 90 ms，一次性在启动时完成。

面积用球面多边形梯形积分算（不是平面近似），所以「已点亮面积 / 可点亮面积」可以横跨不同纬度比较。

数据仅供个人记录使用，版权归原数据提供方。

## 六、隐私

- 定位坐标只在本机做多边形判定，**不上传、不落第三方**
- 照片只写在本机沙盒里（`Application Support/FootprintGlobe/photos/`），**不压缩上传、不生成缩略图联网**

- 所有记录保存在沙盒内，卸载 App 即彻底删除（钥匙串里的密码哈希也会随 App 一起清掉）

## 八、怎么验收这一版（M1-V3）

按顺序走一遍，10 分钟能看完：

1. **晨昏线没了** —— 看球面：没有那种一半亮一半黑、交界处发灰的分界了，只有左上角一块自然的高光。多等几分钟、或者转地球，球面明暗都不再变化。
2. **海报分享（重点）** —— 底部 dock 的护照按钮 → 左上角分享按钮。应该在半秒内弹出「足迹海报」窗口并显示转圈，然后出图。点「分享」能正常弹出系统分享面板（微信 / 存文件 / 隔空投送），点「存到相册」能在相册里找到。**如果屏幕出现「地球那层没渲染出来」，说明走了简化版降级，数据仍然是对的。**
3. **自动旋转** —— 手指离开屏幕，什么都不碰，数到 8 秒，地球开始慢慢自转（约 90 秒一圈）。手指一碰立刻停。`设置 → 地球` 关掉「自动旋转」就完全不转。
4. **陀螺仪视差** —— 真机上把手机左右轻微倾斜：球面会跟着偏几度，星空不动，有明显的层次感。模拟器上 `设置 → 地球` 里那一行会显示「不可用」。
5. **四套主题** —— `设置 → 外观` 依次点「深空 / 日光 / 纸图 / 霓虹」：星空、地球、卡片、文字颜色应该整体换一遍；纸质地图是牛皮纸底 + 砖红标记 + 球面撒着纸点，霓虹是紫黑底 + 青色发光。杀掉 App 重开，还是上次选的那套。
6. **不注册也能用** —— 全新安装，不要注册。地球、定位、记录、护照、海报，全部照常。首页左上角**没有**头像（因为没登录）。
7. **注册** —— `设置 → 账号 → 注册 / 登录`，手机号填 11 位（比如 13800008888），密码 ≥ 6 位，两次输一样。点注册，应该直接进登录态，账号行变成昵称 + `138 **** 8888`。
8. **头像和昵称** —— 在账号页点大头像旁边的小相机，从相册选一张；改昵称后点「保存」。回首页，左上角应该出现这个小头像，点它直接进设置。
9. **密码是真的在加密** —— 注册完重开 App，还是登录态；点「退出登录」后再用错密码登录，提示「密码不对」；用对的密码能回来，头像昵称都还在。
10. **重设密码** —— 同一个手机号再注册一次（密码换成新的），应该直接成功并登录，相当于重设密码。
11. **老数据不丢** —— 从 0.4.0 升级上来，之前的城市、时间、故事、标签、照片、主题设置应该原样还在（主题如果是「深色」会显示成「深空」）。

已知限制：台湾省数据源只有省级轮廓，暂按一个整块显示；日本只有都道府县级（没有市町村）；北极是合成区域，不能靠定位自动记录，只能手填；长时间静止系统可能不唤醒，靠「待确认」兜底；还没有 iCloud / 跨设备自动同步（这一版只做到手动 zip 备份）；账号只在这台手机上，没有密码找回，换机或恢复备份后需要重新注册。
